## B. Registro de decisiones (ADR)

| ADR     | Decisión                                                                                                                                                                                                                              | Estado                                               | Alternativas descartadas                                                                              |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| ADR‑001 | **Next.js App Router + Supabase + Vercel** con e‑commerce a medida (no Shopify/Tiendanube/Medusa)                                                                                                                                     | ✅ Definido por el cliente                           | Shopify (fees + lock‑in), Medusa (sobredimensionado para 53 SKUs), WooCommerce headless (mantiene WP) |
| ADR‑002 | Pasarela de pago: interfaz `PaymentProvider`; implementación inicial **pendiente Q‑01**. Recomendación: **Mercado Pago Checkout Pro** (mayor conversión en AR, cuotas, QR, dinero en cuenta) + mantener Getnet si tiene mejores tasas | ⏳                                                   | Stripe (no opera ARS localmente)                                                                      |
| ADR‑003 | Admin a medida dentro del mismo proyecto Next.js (no CMS headless)                                                                                                                                                                    | ✅ Propuesto                                         | Payload/Sanity (otra pieza para 53 productos)                                                         |
| ADR‑004 | Búsqueda con Postgres FTS + trigram                                                                                                                                                                                                   | ✅ Propuesto                                         | Algolia/Meilisearch (costo, otro servicio) — reconsiderar > 2.000 productos                           |
| ADR‑005 | Montos en enteros ARS, snapshot de precios en `order_items`                                                                                                                                                                           | ✅ Propuesto                                         | numeric con decimales                                                                                 |
| ADR‑006 | Emails con Resend + React Email                                                                                                                                                                                                       | ✅ Propuesto                                         | SendGrid, SMTP Hostinger                                                                              |
| ADR‑007 | Mantener URLs `/producto/<slug>` de WooCommerce                                                                                                                                                                                       | ✅ Propuesto                                         | Nuevas URLs + 301 (riesgo SEO innecesario)                                                            |
| ADR‑008 | Carrito en DB (no localStorage)                                                                                                                                                                                                       | ✅ Propuesto                                         | Zustand + localStorage (precios desincronizados, sin recuperación de carrito)                         |
| ADR‑009 | Variantes de imagen pre‑generadas en el VPS + loader propio                                                                                                                                                                           | ✅ Propuesto                                         | Vercel Image Optimization / Supabase Image Transformation (costo por transformación)                  |
| ADR‑010 | **Sin deploys automáticos**: `git.deploymentEnabled: false`, workflows manuales con aprobación al cerrar cada fase                                                                                                                    | ✅ Definido por el dueño                             | Previews por PR (más builds y costo)                                                                  |
| ADR‑011 | VPS Contabo para integraciones, colas, imágenes y backups; webhook de pagos se queda en Vercel                                                                                                                                        | ✅ Definido por el dueño (VPS) / propuesto (reparto) | Todo en Vercel (costo/timeouts), pagos en el VPS (punto único de falla)                               |
| ADR‑012 | WebGL con R3F solo en home/landings, cargado post‑LCP con tiers y póster                                                                                                                                                              | ✅ Propuesto (go/no‑go tras spike F2‑07)             | WebGL en todo el sitio; video pesado como hero                                                        |

## C. Riesgos

| #    | Riesgo                                                                                                             | Prob. | Impacto          | Mitigación                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------------------ | ----- | ---------------- | ------------------------------------------------------------------------------------------------------------- |
| R‑01 | Credenciales expuestas en el zip (DB, salts, hashes)                                                               | Alta  | Alto             | F0‑01 inmediato; no versionar el zip                                                                          |
| R‑02 | Demora en credenciales/contrato de pasarela                                                                        | Media | Alto             | Arrancar con sandbox de MP; abstracción `PaymentProvider`                                                     |
| R‑03 | Contenido incompleto retrasa el go‑live                                                                            | Alta  | Medio            | Checklist con responsable y fecha; lanzar productos sin contenido como `draft`                                |
| R‑04 | Venta online de productos que puedan considerarse medicamentos/magistrales (ANMAT restringe su venta por internet) | Media | **Alto** (legal) | Consulta legal (F0‑08); flag `requires_prescription` → "consultar por WhatsApp" en lugar de comprar           |
| R‑05 | Pérdida de SEO en la migración                                                                                     | Media | Medio            | URLs compatibles + 301 + monitoreo Search Console                                                             |
| R‑06 | Webhooks de pago duplicados o fuera de orden                                                                       | Media | Alto             | Idempotencia por `provider_payment_id`, consulta al proveedor antes de actualizar                             |
| R‑07 | Sobreventa por concurrencia                                                                                        | Baja  | Medio            | `SELECT … FOR UPDATE` + reservas con vencimiento                                                              |
| R‑08 | Inflación: cambios de precio frecuentes                                                                            | Alta  | Medio            | Actualización masiva de precios por % en admin                                                                |
| R‑09 | Políticas RLS mal escritas exponen datos                                                                           | Media | Alto             | Tests de RLS en CI, `supabase db lint`, Security Advisor de Supabase                                          |
| R‑10 | Dependencia de una sola persona técnica                                                                            | Media | Medio            | Documentación, CLAUDE.md, ADRs, código tipado y testeado                                                      |
| R‑11 | Máquina de desarrollo sin Node/Python/Git instalados (detectado en esta sesión)                                    | Alta  | Bajo             | F1‑01                                                                                                         |
| R‑12 | WebGL degrada LCP/INP en celulares de gama baja o WebViews de Instagram/TikTok                                     | Media | Alto             | Spike medido (F2‑07), tiers, póster LCP, tests de FPS en CI, go/no‑go                                         |
| R‑13 | VPS caído o lento afecta el checkout                                                                               | Media | Medio            | Timeout 2,5 s + fallback a tarifa plana + Uptime Kuma con alertas                                             |
| R‑14 | Andreani exige volumen mínimo para dar API                                                                         | Media | Medio            | Arrancar con MiCorreo + tarifas planas; Andreani cuando haya credenciales                                     |
| R‑15 | VPS sin hardening expuesto a Internet                                                                              | Media | Alto             | Checklist V‑02 antes de abrir puertos; secretos dedicados y revocables                                        |
| R‑16 | Deploys manuales olvidados → staging desactualizado                                                                | Baja  | Bajo             | Gate de fin de fase obligatorio en el backlog                                                                 |
| R‑18 | APIs argentinas (MiCorreo, Andreani, ARCA) bloquean o limitan IPs europeas                                         | Media | Alto             | Prueba V‑15 en la semana 3; plan B: proxy de salida AR, VPS chico en otra región o función en Vercel `gru1`   |
| R‑19 | Latencia EU ↔ Supabase São Paulo en jobs del worker                                                                | Alta  | Bajo             | Upserts en lote, RPCs, jobs asíncronos                                                                        |
| R‑17 | Costos de Vercel/Supabase por encima de lo previsto                                                                | Baja  | Medio            | Spend Management con tope duro, revisión mensual de _Usage_, presupuestos en [11](11-performance-y-costos.md) |
